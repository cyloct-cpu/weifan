## 色板（来自规范页）

| 角色 | 色值 | 含义 |
|---|---|---|
| 主色 Primary | `#FD6C4E` | **暖 = 发件**：中文变出去 |
| 辅助 Secondary | `#2FB6FF` | **冷 = 收件**：外语变回来 |
| 强调 Accent | `#00E9DD` | 通用 / 成功态 |
| 正文 Text | `#161B22` | 浅色底文字 |
| 深底 Dark | `#0F1720` | 深色底 |

渐变：

- 暖色渐变 `#FF4353 → #FD6C4E(42%) → #FF9064(80%) → #FFC4A6`
- 冷色渐变 `#4C9BF7 → #2FB6FF(45%) → #00E9DD`

## 界面用色规则

界面里**唯一的彩色就是「方向」**，结构一律中性：

- 发件相关（工具栏、语气、直接替换、阈值）→ 暖色 `#FD6C4E`
- 收件相关（自动翻译、译文展示）→ 冷色 `#2FB6FF`
- 双向通用（服务密钥、术语表）→ 强调色 `#00E9DD` 或双色并置
- 其余（容器、文字、边框）→ 中性：浅色底 `#F4F6F8` / 白卡；深色底 `#0F1720` / `#161C24` 卡

## 已知限制

16px 下两条尾巴必然消失（像素不够），资产包的做法是 ≤32 档直接用去尾版。
扩展图标 PNG 已按此处理好，直接用，不要自行重渲染。
