# 微翻 iOS 安装指南（发给使用者，可外发）

> 你收到的是 `微翻-未签名.ipa`。因为不是从 App Store 下载，需要用你自己的
> Apple ID 签名后安装（免费，7 天续签一次）。**按你手里的设备三选一**。

## 方案 A：有 Mac → AltStore（最省心，自动续签）
1. Mac 下载 AltServer：https://altstore.io → 拖入「应用程序」→ 打开（菜单栏钻石图标）
2. 菜单栏 AltServer → Install AltStore → 选你的 iPhone（首次插线）
   - 登 Apple ID 时需要「App 专用密码」：appleid.apple.com → 登录与安全 → App 专用密码 → 生成
3. iPhone：设置 → 通用 → VPN与设备管理 → 信任你的开发者证书
4. 把 `微翻-未签名.ipa` AirDrop 到手机 → 文件 App 里长按 → 分享 → AltStore → 安装
5. 之后手机连着和 Mac 同一个 WiFi 就会自动续签，无感使用
   （出差超过 7 天不在同一 WiFi，回来打开 AltStore 点刷新即可，数据不丢）

## 方案 B：有 Windows 电脑 → 爱思助手（国内最普及）
1. 电脑装爱思助手 → 工具箱 → 自签/IPA 签名
2. 登你的 Apple ID → 添加 `微翻-未签名.ipa` → 开始签名（会下载描述文件，跟着点）
3. 数据线连 iPhone → 爱思里安装签好的包
4. 手机上信任开发者证书（同方案 A 第 3 步）
5. 每 7 天连一次电脑重签（爱思会提示到期）

## 方案 C：没有电脑 → SideStore（手机自续签）【详细版】

### 它是怎么工作的（3 个关键认知）
1. **续签靠一个「伪装 VPN」**：SideStore 装好后会让你开启一个名为 SideStore 的
   VPN 描述文件——它不代理你的日常流量，只是给 SideStore 的续签进程开一条
   手机本机的通道，让 App 能在设备上直接和 Apple 服务器说话。
2. **这个 VPN 和其他 VPN 互斥**：iOS 全系统同时只允许一个活动的 VPN。
   开着 Shadowrocket/小火箭时 SideStore 续签就是停的——要用微翻挂 VPN 的人
   必须养成习惯：续签窗口期先关小火箭，续完再开。
3. **首次配对需要一次电脑**：生成「配对文件」必须用电脑连一次手机（之后永不需要）。

### 安装步骤（一次性，约 20 分钟）
1. 电脑（Mac/Win 都行）下载 JitterbugPair：
   github.com/SideStore/JitterbugPair/releases → 选对应平台
2. 手机用数据线连电脑（点「信任」）→ 运行 JitterbugPair
   → 生成一个 `.mobiledevicepairing` 配对文件
3. 把配对文件 AirDrop/微信传回手机（存到「文件」App）
4. 安装 SideStore 本体（两种方式任选）：
   a. 借电脑装 AltServer → 用它装 SideStore.ipa（sidestore.io 下载）
   b. 或用爱思助手自签安装 SideStore.ipa
5. 手机上信任开发者证书（设置 → 通用 → VPN与设备管理）
6. 打开 SideStore → 登 Apple ID（两步验证会要求验证码，正常走）
   → 提示导入配对文件 → 选第 3 步传来的那个
7. 按提示安装「SideStore VPN」描述文件并允许
8. SideStore 内 → ➕ → 从「文件」选 `微翻-未签名.ipa` → 安装
9. 完成后先手动点一次刷新，确认状态变绿

### 日常使用节奏
- 保持 SideStore 的 VPN 开关为开（设置 → VPN 里那个）→ 它会尽量自动续签
- **保险习惯**：每 5-6 天手动打开 SideStore → 看微翻剩余天数 → 点刷新
- 续签那一分钟：关 Shadowrocket → 刷新 → 重新开 Shadowrocket
- App 数据/WhatsApp 配对在续签时完全保留

### 常见问题
- **「无法与 App Store 连接/anisette 错误」**：Apple 风控，换一个网络环境（关 WiFi 用蜂窝）重试
- **iOS 大版本更新后续签失败**：需重新跑一次 JitterbugPair 生成新配对文件
- **App ID 上限**：免费号 7 天 10 个，微翻占 3 个
- **实在嫌麻烦**：₆₈₈/年 TestFlight 或换安卓版（免签直装永久用）

## 首次使用微翻（所有人通用）
1. 需要另一部装着 WhatsApp 的手机扫码关联：微翻 → 聊天 Tab → 配对页
   （WhatsApp → 设置 → 已链接的设备 → 链接设备 → 扫码）
2. 国内网络请开着 VPN/代理再打开微翻，否则连不上 WhatsApp
3. 消息收发、翻译、通话功能见随包说明

## 常见问题
- **App 打不开了**：签名到期，按上面方案续签一次即可，数据不丢
- **提示无法验证 App**：没信任开发者证书，见方案 A 第 3 步
- **Apple ID 提示已达到 App 上限**：免费账号 7 天内最多注册 10 个 App ID（本 App 连
  键盘/分享扩展占 3 个），等额度刷新或换 Apple ID
- 想要「装一次长期用」：需要 ¥688/年的开发者账号走 TestFlight，或换安卓版（免签直装）
