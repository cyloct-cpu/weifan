**三只拦路虎（后续 agent 必读，都已写进代码注释）**：

1. **xcframework 是旧的**：`ios/Frameworks/WeifanProtocol.xcframework` 停在 11-04 08:18，协议头里没有 OnQRCode/OnQRImage（中午才加），导致 QR 回调永远不触发。**重建方法**：`cd weifan-protocol && gomobile bind -target=ios,iossimulator -o WeifanProtocol.xcframework -bundleid com.weifan.protocol ./mobile`（gomobile/gobind 在 `~/go/bin`），然后同步 `Headers/*.h` 到 `ios/Frameworks/ProtocolHeaders/`。诊断手法：对 handler 逐个 `responds(to: Selector)` 即刻暴露。
2. **Xcode 27 模块解析**：per-file 增量编译里，无论 target 直接挂 xcframework、-F 指向 slice、还是 SwiftPM binaryTarget，clang 依赖扫描都解析不出 `WeiFanProtocol` 模块（GRDB 的 `-fmodule-map-file` 会进一步搅局）。**最终方案 = 桥接头**：`Sources/App/ProtocolBridging.h` 直接 `#import "Mobile.objc.h"` + `OTHER_LDFLAGS: -framework WeifanProtocol`，完全绕开模块系统。配套约定：gobind 回调类用 `NSObject + XxxProtocol`（桥接导入后协议名带 Protocol 后缀），**不要**继承代理基类（运行时 go_seq 崩）。
3. **SQLite 子查询丢 rowid**：`SELECT * FROM (子查询) ORDER BY rowid` 报 no such column——子查询投影不带 rowid。已改单层 `SELECT rowid, * ... LIMIT ?` + Swift 侧 `.reversed()`。
