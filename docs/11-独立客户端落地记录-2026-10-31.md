# 11 · 独立客户端落地记录（2026-10-31）

> 本文记录「微翻独立 WhatsApp 客户端」第一次端到端打通的全过程。
> 决策依据见 `docs/10-对齐同类客户端-差距分析与方案-2026-10-31.md`。

## 一、已完成（全部实测通过）

### 协议层（新仓库 /Volumes/CY-MAC/自动翻译/weifan-protocol）
- Go 模块：whatsmeow fork（上游 2026-10-30 版）+ gomobile 桥 `mobile/`
- 门面 `WeifanClient`：Connect / Disconnect / Logout / IsPaired / IsConnected /
  **PairWithPhone（手机号配对码）** / PairWithQR / SendMessage / 三个 Listener 回调
- 关键实现点（踩过才对）：
  1. SQLite 连接串必须带 `?_foreign_keys=on`，否则 `container.Upgrade` 直接报错；
  2. 代理用 `client.SetProxyAddress()`，**必须每次重建 client 后重设**（PairWithPhone 会重建
     内层 client，代理会丢——已在 `newInnerClient` 里统一处理）；
  3. 国内网络必须走代理，`proxyURL` 参数为空则直连；
  4. 桌面冒烟工具 `cmd/smoke`：`WF_PROXY=socks5://… go run ./cmd/smoke <dir> <phone>` 可直接验证配对码。
- **真实验证**：桌面端与 Android 模拟器各拿到一次真实配对码（6GFZ-5R2D / JTCK-PS7H），
  证明代理 → WebSocket → 握手 → PairPhone 全链路可用。
- 产物：`weifan-protocol.aar`（49MB，4 ABI）。iOS 构建脚本 `build-ios.sh` 已备好（Xcode 阻塞）。

### Android 端（主仓库 android/）
- 新增：
  - `WeiFanApplication.kt`：协议客户端全局单例（带代理）
  - `PairingActivity.kt`：配对页（手机号 → 8 位码大字显示 + 三步引导）
  - `ChatListActivity.kt`：主页（聊天列表 + 未配对引导卡 + 翻译工具入口 + 代理设置）
  - `ChatActivity.kt`：会话页（收件自动双语、发件「译」替换后手动发送）
  - `chat/ChatEngine.kt`：协议层 → ChatDb → core.Engine 翻译内核的粘合层
  - `data/ChatDb.kt`：零依赖 SQLiteOpenHelper（chats / messages 两表）
  - `ios/`（weifan-protocol 内）：ProtocolStore / PairingView / ChatViews Swift 骨架
- 修改：
  - Manifest：LAUNCHER 改为 ChatListActivity；注册 PairingActivity / ChatActivity / WeiFanApplication
  - `app/build.gradle.kts`：引入本地 `libs/weifan-protocol.aar`
  - `Prefs.kt`：新增 waProxy / waTargetLang / waAutoTranslateIncoming / waAutoSend
  - 原 MainActivity（设置页）保留不动，从聊天列表可进
- **验证**：模拟器实测——主页渲染 ✓ → 配对页流程 ✓ → 真实配对码下发 ✓ →
  无代理时错误提示 ✓ → 全程无 FATAL ✓。APK 140MB（4 ABI，后续可裁 2 ABI 减半）。

## 二、下一步（按优先级）

1. **真机配对**：模拟器验证只到"拿到配对码"，真正的配对完成需要在官方 App 里输入码 ——
   用小号试，别用主号。
2. **收发闭环**：配对成功后 HistorySync 会把会话同步进来（onMessage 逐条落库），
   验证聊天列表出会话、收件自动出中文。
3. **翻译配置打通**：会话页「译」按钮依赖 core.Engine，先在设置页配好任意一家服务商（百度最简单）。
4. **APK 瘦身**：`gomobile bind` 只编 `android/arm64` + `android/x86_64`，体积减半到 ~70MB。
5. **媒体消息**：第一阶段只处理文本；图片/语音在 Go 层 `extractText` 已跳过 caption 之外的媒体。
6. **iOS**：装 Xcode 后跑 `weifan-protocol/build-ios.sh` 出 xcframework，Swift 骨架已就位。
