# 微翻 · 品牌与 UI 重构方案（v8 · 已落地）

> 日期：2026-10-31　范围：品牌命名 / 标志 / 三端界面
> **v2 修订**：① 标志概念整体更换（不再做对话气泡）；② 界面不再另立中性色体系，**全面以 WhatsApp 原版为准**，`WaSpec.kt` 作为唯一 token 源。
> **v3 修订**：标志改为**带色**方案，并对照库内大厂构造（Figma / Slack / Google Photos 的模块化多色件）重做。
> **v4 修订**：抽象几何方向全部放弃，改走字母路线。
> **v5 修订**：按库内成熟字母标志（npm / Kotlin / Manjaro / Vue）的构造法重做，补上尺寸阶梯、像素测试与货架检验。
> **v6 修订**：标志改为 **W + F 字母组合**（名字两个首字母）。
> **v7 修订**：WF 不再并排摆放，而是先合并成一块实体再沿 45° 切开。
> **v8（实施）**：最终采用用户提供的手写体「W」作为唯一标识；界面色板按 WhatsApp 官方规格落地到代码。
>
> 说明：v1–v7 是同一件事的探索过程（气泡 → 卡片 → 括号 → 箭头 → W → 切割），
> 其中间概念图与样机在落地时已清理，本文只保留**结论、理由与最终文件**。
> 前提出自用户：原有品牌色与标志作废；UI 尽量贴近原版 WhatsApp。

## 1. 标志：为什么换、换成什么

### 1.1 两个方案被否的原因（有实测）

**气泡方向（上一轮）**：产品长在 WhatsApp 里，再用气泡当标志，等于把 WhatsApp 自己的图标再画一遍。放在顶栏或通知栏里，用户会分不清哪个是 WhatsApp。

**互字方向（本轮试做）**：概念很好——「互」是汉字里少见的**点对称**字形，转 180° 还是它自己，正好是"翻"。但实际做出来在 26dp 顶栏与 16px favicon 上**读成"5"**（当时实测对比过）。字形类标志在 24dp 以下必须有专门的小尺寸切图，成本与收益不成正比，因此降为备选。

### 1.2 采用：WF · 一刀斜切

**一句话**：把 W 和 F 合成一块实体，沿 45° 切一刀，两片沿缝各让开 3——切完左边是深绿、右边是亮绿，两片都带着对方的颜色。

**为什么不是"并排摆两个字母"**：并排只是排版，切开才是设计。切开之后有三件事同时成立：
1. **一个整体**：先合并再切，视觉上是一个实体被切开，不是"A 字母旁边放 B 字母"；
2. **缝有含义**：W 的右斜边与 F 的左上角同时被切到，两片互为对方颜色——就是"同一句话的两面"这条产品主张的形状版；
3. **可延展**：这条缝可以做 180ms 的错开—合拢，作为切换语种的唯一动效。

**刀口参数**（`tools/w_band.py` 生成，可直接调）：

| 参数 | 值 | 作用 |
|---|---|---|
| 角度 | 45°（沿 W 右斜边方向） | 与字母自身的斜角同族，不像外来的直尺线 |
| 位置 | `c = 268`（直线 y = −x + c） | 算出来的：让 W 右斜边与 F 左上角同时中刀 |
| 缝宽 | 11 | 32px 时仍有约 1.4px 可见缝 |
| 错位 | 3（沿法线各 3，共 6） | 刚好看得出是两片，又不会散开 |

**三档尺寸**：

| 尺寸 | 文件 | 说明 |
|---|---|---|
| ≥32px | `u1-cut.svg` | 两色斜切，缝可见 |
| ≥24px | `u2-cut-tile.svg` | 绿片 + 白／薄荷两片，单色场景下靠明度差保住缝 |
| ≤20px | `w2-tile.svg` | 只留 W（16px 两字母必糊，实测） |

**保守替代**：`z6-cut-vertical.svg`——竖直切线、两片上下各错开 7。更好认，但"切"的语义弱。

**测试**：当时做过三级切法对比与顶栏 20dp / App 图标的语境验证。

### 1.3 备选与已排除

| 方案 | 结论 |
|---|---|
| **双面卡**（一张圆角方卡 + 45° 斜缝，两半深/亮绿） | **第一备选**。最像成熟产品，单色白标也好；但剪影是普通圆角方形，图标阵列里不够跳 |
| **双向箭头 ⇄**（两色实心箭头） | 语义最直给、小尺寸最清楚；但箭头是公共符号，做不成独占剪影 |
| 互字 | 概念最好（点对称＝翻），实测 26dp 读成"5"（当时实测） |
| 折面卡片 / 翻页角 | 有"翻"的动作，但 16px 退化成"带缺口的方块" |
| 双向双尾气泡、折角气泡、引号对、W 单字 | 依次否决：接缝刀片化 / 与 WhatsApp 同族 / 读成 9P / 中锋自交 |

### 1.4 已排除的其他方向

| 方向 | 否决原因 |
|---|---|
| 双向双尾气泡 | 尾巴一长就读成螺旋桨；缩短后在圆角处留下刀片状接缝 |
| W 单字（WeFlip 首字母） | 手绘 W 中锋夹角约 30°，等宽描边必然自交，需专业字体工具重绘 |
| 引号对 | 读成两个 9 / P，语义是"引用"不是"翻译" |
| 折角气泡（上一轮 A） | 概念成立，但与 WhatsApp 气泡同族，且用户已要求换概念 |
| 互字 | 概念最好，但 26dp 读成"5"（见 §1.1） |

## 2. 界面基准：WhatsApp 原版

### 2.1 唯一 token 源

`android/app/src/main/java/com/weifan/app/WaSpec.kt` 已经是反编译得到的 WhatsApp 规格。**三端都以它为准**，不再另立一套：

| 角色 | 值 | 出处 |
|---|---|---|
| 顶栏绿 | `#128C7E` | `WaSpec.GREEN` |
| 深绿（设置页标题/强调） | `#075E54` | `WaSpec.GREEN_DARK` |
| 品牌亮绿（未读徽标） | `#25D366` | `WaSpec.GREEN_LIGHT` |
| 发送圆钮 | `#06CE9B` | `WaSpec.INPUT_CIRCLE_GREEN` |
| 聊天壁纸 | `#F5F1EB` / 涂鸦 `#EAE0D3` | `WaSpec.WALLPAPER_*` |
| 发件气泡 | `#E0FCD6` | `WaSpec.BUBBLE_SENT` |
| 收件气泡 | `#FFFFFF` | `WaSpec.BUBBLE_RECEIVED` |
| 主文字 / 次文字 | `#111111` / `#8E8E93` | `WaSpec.TEXT_*` |
| 已读双勾 | `#34B7F1` | `WaSpec.READ_RECEIPT` |
| 输入区底 / 搜索底 | `#F2F2F7` | `WaSpec.INPUT_BG` / `GRAY6` |
| 气泡圆角 / 最大宽 | 10dp / 280dp | `WaSpec.BUBBLE_*` |
| 顶栏高 | 56dp | `WaSpec.TOOLBAR_HEIGHT_DP` |

**产品新增只有一个色**：译文行 `#0A7EA4`（`WaSpec.TRANSLATE_TEXT`）。它是蓝绿系里偏青的一档，既不与 WhatsApp 的绿争主次，也不与蓝勾混淆；13sp（`TRANSLATION_TEXT_SP`）。

### 2.2 品牌只能出现在 WhatsApp 不放东西的地方

| 位置 | 做什么 | 为什么 |
|---|---|---|
| 启动图标 / 通知图标 | 翻面卡片，绿底白标 | 唯一的强露出 |
| 会话列表顶栏 | **只放"微翻"文字**，左对齐，样式与 WhatsApp 的"WhatsApp"完全一致 | WhatsApp 顶栏没有图标，加图标就是偏离原版 |
| 设置页顶栏 | `#075E54` 深绿 + 返回箭头，同 WhatsApp | 保持 |
| 扩展面板顶部 | 26dp 白色 mark + "微翻" | 浏览器里没有 WhatsApp 的语境，这里需要品牌 |
| 关于页 | 完整锁版 + 版本号 | 常规 |

**不要做的**：会话页右侧的圆形浮标（旧 logo 已在那里，遮挡消息）——取消，功能并入输入框右侧的「译」钮，样式照抄 WhatsApp 的发送圆钮（40dp 圆、`#06CE9B` 底、白色图标）。

## 3. 三端页面规格

### 3.1 Android · 会话列表（对齐 `ChatListActivity`）

```
┌────────────────────────────────────────┐ 56dp  #128C7E
│ 微翻                        🔍   ⋮    │ 17sp 600 白
├────────────────────────────────────────┤
│ ( 搜索会话                        )    │ 36dp 胶囊  #F2F2F7
│ (全部) (未读) (群组)                   │ 28dp chip，#128C7E 文字
├────────────────────────────────────────┤
│ ⬤ 张伟 · 中东客户            10:24   │ 头像 50dp，行高 72dp
│   Hello! Do you have this in stock?    │ 14sp #667781
│   你好！这个有现货吗？                 │ 13sp #0A7EA4  ← 产品新增
├────────────────────────────────────────┤
│ ⬤ Maria · 拉美客户           09:41 ④│ 未读徽标 #25D366
│   Hola, ¿cuál es el precio FOB?        │
│   你好，FOB 价格是多少？               │
└────────────────────────────────────────┘
                                    (✎)      FAB #25D366
```

规则：
- 第二行**永远是中文**（对方说外语时），这是产品承诺，也是与 WhatsApp 列表唯一的差异点。
- 译文行用 `#0A7EA4` 而不是灰色：一眼分清"原文/译文"，不需要图例。
- 未读徽标、时间戳、分隔线全部照 `WaSpec`，不做美化。

```

│ ←  Maria · 西语             📞  ⋮     │
├────────────────────────────────────────┤ 壁纸 #F5F1EB + 涂鸦

│  └──────────────────────────┘          │
│          ┌────────────────────────┐    │ 发件：#E0FCD6
│          │ 这批 500 件能做吗      │    │
│          │ ───────────────────────│    │
│          │ Can you do 500 pcs FOB?│    │
│          │                09:42 ✓✓│    │
│          └────────────────────────┘    │
├────────────────────────────────────────┤
│ 将译为 English · 长按切换        [译]  │ 32dp 提示条 #F2F2F7
│ ( 输入中文…                    ) ( ➤ ) │ 40dp 圆钮 #06CE9B

```

三处必须守住：
1. **气泡是 WhatsApp 的气泡**：10dp 圆角、`#E0FCD6`/白、时间戳与双勾位置不动。译文行是气泡内的**第二段**，用 1px 分隔线，结构等同 WhatsApp 的"引用回复"。
2. **发送口径不变**：点发送前不自动发送；「译」钮只译不送，`Ctrl/Cmd+Enter` 等价。译文与原文同框，用户看得到自己发的是什么。
3. **不新增 chrome**：没有额外的工具条、没有侧栏、没有浮标。

WhatsApp 的设置页就是"分组 + 行 + 右箭头"，本页照此结构，不引入卡片、不引入九宫格胶囊。

### 3.4 浏览器扩展 · 面板（360 宽）

浏览器里没有 WhatsApp 的外壳，但必须让人认出是同一个产品：用同一套绿、同一套圆角、同一套行高。

```
┌──────────────────────────────────────┐
│ ◤微翻                     ☀   ⚙     │ 40dp，#128C7E，白色 mark 22dp
├──────────────────────────────────────┤
│  自动检测  ⇄  英语                   │ 语言对，1 行
│                                       │
│ ┌───────────────────────────────────┐ │
│ │        翻译选区 / 剪贴板           │ │ 44dp，#06CE9B，白字
│ └───────────────────────────────────┘ │
│                                       │
│ 划词 ●   悬停 ●   自动填入 ○         │ 3 个开关，#128C7E 轨道
│ ───────────────────────────────────── │
│ 上次：百度 · 今日 3.2k 字符       →   │ 1 行状态，点进设置
│                                       │
│ [ 文本翻译 ]        [ 文档翻译 ]      │ 两枚次按钮，#F2F2F7 底
└──────────────────────────────────────┘
```

与现状的差别（结构层面）：
- 8 个平级入口 → **1 个主动作 + 3 个开关 + 2 个次入口**；服务商、语气、单测下沉到设置页。
- 主按钮从"暖色渐变"改为 `#06CE9B` 纯色，与 Android 发送钮同色——用户在两处看到同一个"要发出去"的颜色。
- 面板不再出现渐变（旧 `--warm-grad` / `--cool-grad` 全部废弃）。

### 3.5 扩展 · 设置页

分组与顺序**与 Android 设置页一致**（翻译服务 → 翻译行为 → 划词与悬停 → 文档 → 外观 → 快捷键），字段按端能力裁剪。行高 56，分组标题 `#075E54` 13sp，右侧箭头同 WhatsApp。

## 7. 风险

| 风险 | 处理 |
|---|---|
| 太像 WhatsApp 会被误认成官方 | 标志与产品名在启动图标/通知/关于页持续露出；设置页顶部标注"第三方客户端" |
| 译文行让气泡变高，一屏条数减少 | 译文行默认展开、可长按折叠为"译"小标签（P2 再做开关） |
| `WeFlip` 名称冲突 | 上架前检索商标/商店/域名；备选 Wefan |
| 蓝绿两色在同一屏 | `#0A7EA4` 只用于译文、`#34B7F1` 只用于双勾，用途不重叠；若仍混，译文改用 `#075E54` |
