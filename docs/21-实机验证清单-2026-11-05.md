# 实机验证清单（2026-11-05 汇总）

> 前提（一次性）：**手机扫码配对**。
> - Android：打开 App → 自动进「关联 WhatsApp」→ 手机 WhatsApp → 已链接的设备 → 链接设备 → 扫码
> - iOS：「聊天」Tab → 配对页（二维码已就绪）→ 同上扫码
> - 建议准备：一个真实对方账号（或家人/小号）、一个测试群（群聊验证用）、一部真机（非模拟器）
> 每项验证完在 ☐ 打勾并记日期；失败项记现象，回 docs/19/20 对应章节排查。
