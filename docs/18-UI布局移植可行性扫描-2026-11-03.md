# UI 布局移植可行性扫描（2026-11-03）

问题：能否把 WATransChat 的 UI 各功能布局**直接移植**到微翻？

一句话答案：**能搬的已经搬完了。** 现有 5 个页面与参考的精确尺寸逐项一致；剩下只有 3 个小缺口，
其余页面对比所需的布局数据在参考包里根本不存在。

---

## 1. 手上到底有哪些"可移植的原始数据"

### 1.1 参考 Android（WATransChat 3.55）——资产最全

| 文件 | 大小 | 内容 |
|---|---|---|
| `SPEC.md` | 1410 行 | 6 个页面的完整控件树，含 **精确 dp / sp / 颜色 / 夜间值** |
| `activity_chat.txt` | 40 KB | 会话页原始 `aapt xmltree` dump（51 个控件节点） |
| `activity_chat_list.txt` | 23 KB | 会话列表（33 节点） |
| `activity_account_login.txt` | 41 KB | 账号登录（50 节点） |
| `activity_login.txt` | 51 KB | 登录（56 节点） |
| `activity_register.txt` | 13 KB | 注册（15 节点） |
| `activity_language_setup.txt` | 9 KB | 语言选择（11 节点） |
| `activity_main.txt` | 9 KB | 主页面（13 节点） |
| `all-resources.txt` | 2.3 MB | 全量资源表（色值/drawable/字符串） |

**这是"直接移植"唯一的物质基础：只有 6 个页面有布局数据。**

### 1.2 参考 iOS（WATransChat 2.82）——没有布局数据

| 项 | 状态 |
|---|---|
| UI 框架 | SwiftUI **纯代码**（包内无 storyboard / xib / nib） |
| 符号表 | 自有类型已 strip（2871 个 Swift 符号几乎全是系统框架） |
| 可获得的 | 1206 条本地化文案（能反推**功能面**） |
| **无法获得的** | **任何布局尺寸、间距、颜色、层级** |

结论：iOS 参考**只能移植功能清单，无法移植布局**。

## 5. 结论：真正"可移植"的只剩 3 项

| # | 缺口 | 参考依据 | 价值 | 工作量 |
|---|---|---|---|---|
| **U1** | **客户语言按钮**（会话级强制语言） | `customerLanguageButton` 40dp + `chat_menu_language_settings`「语言设置」 | **高**：外贸客户常混用语言（荷兰客户说英语），自动检测会错，锁定后翻译稳定 | ~30 分钟 |
| **U2** | 头像环 `headerAvatarBg` | `bg_avatar_ring` | 低（纯视觉） | ~10 分钟 |
| **U3** | 独立麦克风按钮 `micButton` | 参考输入区 48dp 圆钮 | 中（少点一次「＋」） | ~20 分钟 |
| — | 语言选择页 | `LanguageSetupActivity` 11 控件 | 低：我们是中文单语，不做多语言 UI | — |
| — | 注册页 | `RegisterActivity` 15 控件 | 无账号体系，不需要 | — |

## 6. 明确不能移植的

| 项 | 原因 |
|---|---|
| 其余 **29 个 Activity** | **包里没有任何布局数据**（只有 Activity 名）。且多为已排除项：AI 客服 8 个、会员 3 个、通话 1 个、FAQ/客服/教程 3 个 |
| **所有图片/图标资源** | `drawable/ic_*` 是参考应用的品牌资产，直接抄是侵权且与我们品牌不符（你早定了"品牌不要换"） |
| **自定义 View 的绘制逻辑** | 布局 dump 只含层级与属性，不含 `onDraw` 代码 |
| **交互行为** | 布局里只有 `id`，点击后做什么要自己写（这也是为什么 B1/B6 这类功能只能靠文案反推 + 自己实现） |
| **iOS 参考的布局** | SwiftUI 编译产物无布局资源，**拿不到** |

---

## 7. 建议

**补 U1（客户语言按钮）** —— 三个缺口里唯一有实际业务价值的：
- 会话页头部加按钮 → 弹语言选择 → 记住到本地（`chatLangMemory` 已有，只需加 UI 与持久化）
- 同时加进长按菜单「语言设置」（对齐参考 `chat_menu_language_settings`）

U2/U3 属锦上添花，可一起做（总计约 1 小时）。

**不建议**为了"移植"去重做已有 5 个页面——它们已经是 SPEC 的 1:1 复刻，重做只会引入回归。
