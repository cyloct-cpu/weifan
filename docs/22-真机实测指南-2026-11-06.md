# 真机实测指南（2026-11-06）

> 配套：docs/21 实机验证清单（勾选用那张）；本文只讲「怎么装、怎么连、按什么顺序测」。
> 双机准备：**A 机**=你的 iPhone（装微翻 iOS）；**B 机**=另一部装着 WhatsApp 的手机
> （安卓可以装微翻安卓版，iPhone 就装官方 WhatsApp 当对端）。

## 0. 产物位置

| 端 | 产物 | 路径 |
|---|---|---|
| iOS | Xcode 工程（含真机 arm64 协议框架，已验证编译通过） | `ios/WeiFan.xcodeproj` |
| Android | 调试 APK（arm64） | `android/app/build/outputs/apk/debug/app-arm64-v8a-debug.apk` |

## 1. iPhone 安装微翻（Xcode 签名直装，免费 Apple ID 即可）

1. iPhone 用数据线连 Mac，手机上点「信任」。
2. Xcode 打开 `ios/WeiFan.xcodeproj` → 选中 WeiFan target → **Signing & Capabilities**：
   - 勾掉「Automatically manage signing」再勾回来，**Team 选你的个人团队**
     （没有就 Xcode → Settings → Accounts → 用 Apple ID 登录，免费账号即可真机调试）。
   - 若报 entitlements（App Group）错误：免费账号支持 App Group；万一报错，
     暂时删掉 Signing & Capabilities 里的 App Groups 再跑（会影响键盘扩展共享设置，聊天主功能不受影响）。
3. iPhone 上：设置 → 隐私与安全性 → 开发者模式 → 打开（iOS 16+ 需要）。
4. Xcode 顶部设备选你的 iPhone → ▶️ 运行。首跑手机上会弹「不受信任的开发者」：
   设置 → 通用 → VPN与设备管理 → 信任你的开发者证书。
5. 微翻图标出现 = 装好（**免费证书 7 天过期**，过期重跑一次 Xcode 即可）。

### iPhone 联网（关键！国内直连被墙）
- **推荐：手机装 Shadowrocket/小火箭 并开启**（TUN/VPN 模式）→ 微翻里 `wa_proxy` 保持空 = 直接走 VPN。
- 不要在微翻里填 `127.0.0.1:端口`——Shadowrocket 无本机 HTTP 端口（与 Mac 模拟器同坑）。
- 判定联网成功：会话列表顶部「连接中…」横条消失。

## 2. Android 对端机（可选）

1. 把 `app-arm64-v8a-debug.apk` 传到手机安装（微信/adb install -r 均可）。
2. 首启关联 WhatsApp 扫码配对（同模拟器流程）。
3. 手机网络能上 WhatsApp 即可（安卓自带 VPN 类 App 或系统代理）。

## 3. 配对（双端各自一次）

- A 机微翻 → 聊天 Tab → 配对页 → 用 B 机的 WhatsApp 扫码（WhatsApp → 设置 → 已链接的设备 → 链接设备）。
- 配对成功自动进会话列表；B 机 WhatsApp 的「已链接的设备」里会出现微翻。

## 4. 实测顺序（对应 docs/21 勾选）

### 第一步：基础消息（约 10 分钟）
| 操作 | 预期 |
|---|---|
| B 机发西语/英语消息给 A 机 | A 机气泡出现**原文+蓝色译文行**（收件自动翻译） |
| A 机输入中文点发送 | B 机收到**外语译文**；A 机绿泡下方留原文小字 |
| A 机看自己消息勾 | 单灰勾=已发出 → 灰双勾=对方收到 → 蓝双勾=已读 |
| ☎️ 挂断重进、杀 App 重开 | 记录都在（本地库） |

### 第二步：语音/视频通话（核心！看「帧数统计」）
1. A 机进会话点 📞 → 界面显示「呼叫中…」→「正在响铃，等待对方接听…」
2. **B 机 WhatsApp 应该响铃**（对方要在线；彻底离线可能既不响铃也不留记录）
3. B 机接听 → A 机显示「通话中 00:xx」+ 底部 `上行 N 帧 · 下行 N 帧`
4. 判读：
   - 双帧都涨 = **双向音频通** ✅
   - 上行涨·下行 0 = B 机的声音进不来（网络/UDP）——换网络或检查 B 机 WhatsApp 权限
   - 双 0 = 我方发送未通 → 截图帧数统计反馈
5. 视频通话 📹：B 机（安卓微翻或官方 WhatsApp）接听后开摄像头 → **A 机应全屏显示对方画面**（本轮新实现）；
   A 机出向视频（摄像头采集）下一轮，所以 B 机暂时看不到 A 机画面，只有声音。
6. 通话记录：挂断后聊天里出现「语音通话（拨出/来电）· 时长」「未接来电」。

### 第三步：媒体（各来一发）
图片/视频/语音条/文档 互发；语音按 🎤 说话（计时应走字）松开发送。

### 第四步：B 组剩余 + D 组
docs/21 B1-B8（静音/扬声器/后台通话）、C 组、D2/D5 群管理、D7 拉黑。

## 5. 常见坑

| 症状 | 原因/解法 |
|---|---|
| 「连接中…」一直不消失 | 手机没开 VPN（国内直连被墙）；开了 VPN 还不行 → 杀 App 重开 |
| 配对码/二维码不刷新 | 同上，网络出口问题 |
| 视频通话 A 机黑屏无画面 | 确认 B 机真的开了摄像头（官方 WhatsApp 视频时点摄像头图标）；帧数统计下行=0 说明 RTP 没通（换网络） |
| 免费证书 7 天后 App 打不开 | 重新用 Xcode 跑一次 |
| 通话接通瞬间 App 退出 | 把崩溃日志（设置→隐私→分析与改进）发我 |
