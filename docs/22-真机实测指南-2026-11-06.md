# 真机实测指南（2026-11-06）

> 配套：docs/21 实机验证清单（勾选用那张）；本文只讲「怎么装、怎么连、按什么顺序测」。
> 双机准备：**A 机**=你的 iPhone（装微翻 iOS）；**B 机**=另一部装着 WhatsApp 的手机
> （安卓可以装微翻安卓版，iPhone 就装官方 WhatsApp 当对端）。

| 端 | 产物 | 路径 |

## 1. iPhone 安装微翻（Xcode 签名直装，免费 Apple ID 即可）

1. iPhone 用数据线连 Mac，手机上点「信任」。
2. Xcode 打开 `ios/WeiFan.xcodeproj` → 选中 WeiFan target → **Signing & Capabilities**：
   - 勾掉「Automatically manage signing」再勾回来，**Team 选你的个人团队**
     （没有就 Xcode → Settings → Accounts → 用 Apple ID 登录，免费账号即可真机调试）。
   - 若报 entitlements（App Group）错误：免费账号支持 App Group；万一报错，
     暂时删掉 Signing & Capabilities 里的 App Groups 再跑（会影响键盘扩展共享设置，聊天主功能不受影响）。
3. iPhone 上：设置 → 隐私与安全性 → 开发者模式 → 打开（iOS 16+ 需要）。
4. Xcode 顶部设备选你的 iPhone → ▶️ 运行。首跑手机上会弹「不受信任的开发者」：
   设置 → 通用 → VPN与设备管理 → 信任你的开发者证书。
5. 微翻图标出现 = 装好（**免费证书 7 天过期**，过期重跑一次 Xcode 即可）。

### iPhone 联网（关键！国内直连被墙）
- **推荐：手机装 Shadowrocket/小火箭 并开启**（TUN/VPN 模式）→ 微翻里 `wa_proxy` 保持空 = 直接走 VPN。
- 不要在微翻里填 `127.0.0.1:端口`——Shadowrocket 无本机 HTTP 端口（与 Mac 模拟器同坑）。
- 判定联网成功：会话列表顶部「连接中…」横条消失。

## 2. Android 对端机（可选）

1. 把 `app-arm64-v8a-debug.apk` 传到手机安装（微信/adb install -r 均可）。
2. 首启关联 WhatsApp 扫码配对（同模拟器流程）。
3. 手机网络能上 WhatsApp 即可（安卓自带 VPN 类 App 或系统代理）。

## 3. 配对（双端各自一次）

- A 机微翻 → 聊天 Tab → 配对页 → 用 B 机的 WhatsApp 扫码（WhatsApp → 设置 → 已链接的设备 → 链接设备）。
- 配对成功自动进会话列表；B 机 WhatsApp 的「已链接的设备」里会出现微翻。

## 4. 实测顺序（对应 docs/21 勾选）

### 第一步：基础消息（约 10 分钟）
| 操作 | 预期 |
|---|---|
| B 机发西语/英语消息给 A 机 | A 机气泡出现**原文+蓝色译文行**（收件自动翻译） |
| A 机输入中文点发送 | B 机收到**外语译文**；A 机绿泡下方留原文小字 |
| A 机看自己消息勾 | 单灰勾=已发出 → 灰双勾=对方收到 → 蓝双勾=已读 |
| ☎️ 挂断重进、杀 App 重开 | 记录都在（本地库） |

### 第二步：语音/视频通话（核心！看「帧数统计」）
1. A 机进会话点 📞 → 界面显示「呼叫中…」→「正在响铃，等待对方接听…」
2. **B 机 WhatsApp 应该响铃**（对方要在线；彻底离线可能既不响铃也不留记录）
3. B 机接听 → A 机显示「通话中 00:xx」+ 底部 `上行 N 帧 · 下行 N 帧`
4. 判读：
   - 双帧都涨 = **双向音频通** ✅
   - 上行涨·下行 0 = B 机的声音进不来（网络/UDP）——换网络或检查 B 机 WhatsApp 权限
   - 双 0 = 我方发送未通 → 截图帧数统计反馈
5. 视频通话 📹：B 机（安卓微翻或官方 WhatsApp）接听后开摄像头 → **A 机应全屏显示对方画面**（本轮新实现）；
   A 机出向视频（摄像头采集）下一轮，所以 B 机暂时看不到 A 机画面，只有声音。
6. 通话记录：挂断后聊天里出现「语音通话（拨出/来电）· 时长」「未接来电」。

### 第三步：媒体（各来一发）
图片/视频/语音条/文档 互发；语音按 🎤 说话（计时应走字）松开发送。

### 第四步：B 组剩余 + D 组
docs/21 B1-B8（静音/扬声器/后台通话）、C 组、D2/D5 群管理、D7 拉黑。

## 5. 常见坑

| 症状 | 原因/解法 |
|---|---|
| 「连接中…」一直不消失 | 手机没开 VPN（国内直连被墙）；开了 VPN 还不行 → 杀 App 重开 |
| 配对码/二维码不刷新 | 同上，网络出口问题 |
| 视频通话 A 机黑屏无画面 | 确认 B 机真的开了摄像头（官方 WhatsApp 视频时点摄像头图标）；帧数统计下行=0 说明 RTP 没通（换网络） |
| 免费证书 7 天后 App 打不开 | 重新用 Xcode 跑一次 |
| 通话接通瞬间 App 退出 | 把崩溃日志（设置→隐私→分析与改进）发我 |

## 8. 附录 B：TestFlight 使用全流程（¥688 账号专属）

> TestFlight = 苹果官方测试分发。App 装在官方「TestFlight」App 里，**每个包 90 天有效**，
> 到期前传新包即续。不需要逐台注册设备、不需要越狱、国内可用。

### 第 1 步：开通账号（一次性）
1. developer.apple.com → Enroll → 用 Apple ID 登录 → 选 Individual（个人）
2. 实名信息填写 → 付款 ¥688 → **24-48h 审核通过**
3. 通过后你在 App Store Connect（appstoreconnect.apple.com）就有了管理后台

### 第 2 步：创建 App 记录（一次性）
1. App Store Connect → 我的 App → ➕ 新建 App：
   - 名称：微翻（可改）；主要语言：简体中文；Bundle ID：`com.weifan.app`；SKU：`weifan`
2. 「App 信息」里补：支持 URL（可先填 GitHub 仓库地址）、分类（商务）
3. 隐私问卷先随意填（只做**内部测试**不强制；做外部测试前认真填）

### 第 3 步：签名配置（一次性，告诉我 Team ID 我直接写进工程）
1. Xcode → Settings → Accounts 确认付费团队已登录
2. WeiFan target → Signing → Team 选付费团队（Keyboard/Share 两个扩展 target 同样操作）
3. 或把 Team ID（10 位字母数字，开发者网站账号页可见）发我，我写死进 project.yml

### 第 4 步：打包上传（每次更新都做，5 分钟）
1. Xcode 选真机或「Any iOS Device (arm64)」→ **Product → Archive**
2. Organizer 窗口 → 选中归档 → **Distribute App → TestFlight & App Store → Upload**
3. 等待处理（App Store Connect → TestFlight 页几分钟后出现，构建号 55/56/…）

> 已在 Info.plist 配好 `ITSAppUsesNonExemptEncryption=false`，
> 不会每次问你出口合规问题。

### 第 5 步：给自己装（内部测试，免审核、即时可用）
1. TestFlight 页 → 左侧「内部测试」→ ➕ 建组 → 把你的 Apple ID（App Store Connect 用户）加进去
2. iPhone 装 App Store 的「**TestFlight**」App → 用同一 Apple ID 登录 → 微翻出现 → 点「安装」
3. 完成。App 蓝色图标带黄点标 TF 角标，和正式 App 并存

- 内部测试上限 100 人（须是你的 ASC 团队成员），**无需苹果审核**
- 家人朋友不在团队？→ 外部测试组：邮箱邀请或公共链接，**需 Beta 审核（一般 24-48h，一次）**，上限 1 万人

### 第 6 步：更新与续期
- 每次发新包：Archive → Upload（构建号 +1，可在 project.yml 改 CURRENT_PROJECT_VERSION）
- 旧包到期前 30 天 TestFlight 会提醒；上传新包所有测试员自动收到更新推送

### 微翻专属注意
- 键盘/分享两个扩展随主 App 一起打包，无需单独传
- TestFlight 包与正式包 Bundle ID 相同，将来上架可无缝替换
- 只做内部测试 = 不碰审核，是最省心的长期自用方案

## 9. 附录 C：AltStore / SideStore 详解（免费自动续签路线）

### 原理
免费 Apple ID 签的 App 7 天过期。AltStore/SideStore 的价值 = **自动重签**：
到期前用你的 Apple ID 把 ipa 重签一遍，App 数据、WhatsApp 配对全部保留。
重签不改变证书额度：每 7 天可注册 10 个 App ID（微翻主 App + 键盘 + 分享 = 3 个），
设备上同时最多装 3 个 AltStore 系 App（微翻算 1 个）。

### 两者的本质区别

| | AltStore | SideStore |
|---|---|---|
| 续签方式 | **Mac 上的 AltServer** 自动重签（手机与 Mac 同一 WiFi 即可，无需插线） | **手机本机自续签**（伪装 VPN 后台跑） |
| 需要电脑 | 装完后 Mac 仍需常开 AltServer | 初次装用电脑，之后不需要 |
| ⚠️ 与 Shadowrocket 冲突 | 无（走网络重签，不占 VPN 槽） | **有**：iOS 只允许一个 VPN 活动，SideStore 的续签隧道和 Shadowrocket 互斥——开小火箭时 SideStore 停 |
| 可靠性 | Mac 开机就在网就稳 | 取决于你记得关小火箭给它续签窗口 |

### 结论（针对你的场景）
- **Mac 常在家/办公室在线 → 选 AltStore**：手机每天回家连 WiFi 自动续，无感
- **没有常开电脑 → SideStore**：但要养成习惯（比如每周挑一次关 Shadowrocket 一分钟让 SideStore 续签）

### AltStore 安装步骤（推荐）
1. Mac 下载 **AltServer**（altstore.io）→ 拖入 Applications → 启动（菜单栏钻石图标）
2. AltServer → Install AltStore → 选你的 iPhone（首次需插线，装完无线）
   - 期间要登 Apple ID，并去 appleid.apple.com 生成一个「App 专用密码」填入（用于推送续签）
3. iPhone：信任开发者证书（通用 → VPN与设备管理）
4. 装微翻：把 `微翻-未签名.ipa` AirDrop 到手机 → 文件 App 里分享给 AltStore → 安装
5. 之后：AltStore 每 2 天左右自动续签（同 WiFi + AltServer 在线）；手动续 = 打开 AltStore 点刷新
6. **续签不动数据**：聊天库、WhatsApp 配对、设置全部保留

### SideStore 安装步骤
1. Mac 装 AltServer（同上）→ 用它把 **SideStore** 装到手机（或按 sidestore.io 的 JitterbugPair 流程）
2. SideStore 内登 Apple ID → 从文件选 `微翻-未签名.ipa` 安装
3. 按提示装 SideStore 的「伪装 VPN」描述文件并允许——它只劫持自己的续签流量
4. 续签时：**关掉 Shadowrocket → 开 SideStore 的 VPN 开关 → 点续签 → 切回来**
5. 其余同 AltStore

### 注意
- 续签失败最常见原因：免费账号 7 天内注册的 App ID 超 10 个（微翻一次占 3 个）
- App 过期没续 = 图标变灰打不开，续完立刻恢复，数据无损
- 两个方案都不影响 WhatsApp 后台收消息（证书有效期内行为与正常 App 一致）
